# moto-7607 局部编辑与首次错误诊断（预注册）

本实验独立于已停止的 P2，不改变其 0/3 strict、0/3 failure reduction 结论。本轮不训练、不做 GRPO、不选择 checkpoint；固定使用 P2 step12 adapter `9370e928…`，单卡 48G。

## D1：编辑前状态的单步自由生成

从三条 verifier 严格通过的教师恢复轨迹中，为每个 `replace_text` / `replace_lines` 动作构造真实执行后的编辑前状态，共7个。上下文包含原始 issue、实际工具 observation 和此前已执行动作，不包含当前教师动作或后续答案。

每状态只做一次 greedy assistant turn，最多1024新 tokens。解析为一个工具调用并真实执行；若为编辑且成功应用，立即运行完整官方 verifier。保存原始 tokens、解析动作、参数合法性、应用结果、patch、测试集合和相对当前前缀/clean baseline的失败变化。

不要求字符串与教师完全相同。判定分层：可解析工具调用；编辑工具及参数合法；补丁可应用；目标源码语义相关；官方 verifier strict success。非编辑、重复旧动作、替换未命中、越界、截断均按实际行为记录。

## D2：首次实质错误

每条教师轨迹冻结三类状态，共9个：

1. `located`：教师已完成定位/读取，尚未开始该段编辑；
2. `before_last_edit`：只剩该轨迹最后一个语义编辑与验证；
3. `before_verify`：教师编辑均已真实执行，只剩验证。

从每个状态做一次 greedy continuation，4096 completion tokens、最多6次新工具调用。完整执行并调用官方 verifier。记录第一处相对可验证恢复链的实质偏离，但允许语义等价动作；分类为解析、错误工具/文件、上下文遗漏、替换未命中、语义错误、预算/截断、过早验证/终止或基础设施问题。

## 决策门槛

- 若 D1 无任何 verifier-improving 编辑，停止在局部代码编辑问题；不扩充完整轨迹、不训练。
- 若 D1 可执行编辑明显改善而 D2 失败，下一计划才转向搜索、状态跟踪和错误恢复。
- 干净7B底座对照是后续独立阶段；只有 D1/D2 能指出要比较的具体状态才启动。14B底座不是默认项。
- 所有基础设施失败单列；不得换 seed 或从多个 checkpoint 中挑成功结果。

证据保存到新的远端目录，包含上下文 provenance、模型/adapter/代码哈希、原始生成、工具轨迹、patch、verifier结果、资源峰值、汇总和SHA-256归档。结束时清理 worker、容器、隧道与临时token。
